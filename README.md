# Дикий Лось — дневник тренировок

Приложение живёт на GitHub Pages (открывается мгновенно и без интернета), а данные хранятся в вашей Google-таблице через Apps Script.

## Перед переездом

Откройте **старую** версию и убедитесь, что в шапке горит «🟢 Сохранено». Новое приложение на другом адресе, поэтому неотправленная очередь и незавершённая тренировка из старой версии туда не перейдут.

## 1. Apps Script (один раз)

1. Откройте таблицу → «Расширения» → «Apps Script».
2. Замените содержимое `Code.gs` новым файлом. Файл `index` (HTML) удалите: он больше не нужен.
3. Сверху выберите функцию **setupToken** → «Выполнить». При первом запуске Google попросит разрешения — подтвердите. Внизу, в журнале выполнения, появится строка «Ваш ключ доступа: …». Скопируйте ключ.
4. «Развернуть» → «Управление развертываниями» → ✏️ у текущего развёртывания:
   - Версия: **Новая версия**
   - Выполнять как: **Я**
   - У кого есть доступ: **Все** (Anyone)
   - «Развернуть». Скопируйте URL веб-приложения (заканчивается на `/exec`).

Доступ «Все» нужен, чтобы страница на GitHub могла обращаться к скрипту. Без ключа скрипт отвечает только «неверный ключ» и данных не отдаёт.

## 2. GitHub Pages (один раз)

1. На github.com: «New repository» → имя, например `moose` → **Public** → «Create repository». Бесплатный Pages работает только с публичными репозиториями. В файлах нет ни ссылок, ни ключей, так что это безопасно.
2. «uploading an existing file» → перетащите все файлы из архива (кроме `Code.gs`) → «Commit changes».
3. «Settings» → «Pages» → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → «Save».
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/moose/`.

## 3. Телефон

1. Откройте адрес сайта, вставьте ссылку `/exec` и ключ → «Проверить и сохранить».
2. Установите приложение на главный экран:
   - Android (Chrome): меню ⋮ → «Добавить на главный экран» / «Установить приложение».
   - iPhone (Safari): «Поделиться» → «На экран „Домой“».

На каждом новом устройстве ссылку и ключ нужно ввести один раз.

## Вкладка «Сегодня» — программа «Перезапуск»

Главный экран для возвращения в форму дома: разборные гантели до 15 кг, гиря 16 кг, коврик.

- **Программа на 8 недель:** 24 тренировки, 3 в неделю, чередуются A и B. Фазы: «Втягиваемся» (недели 1–2, около 20 минут), «Набираем ход» (недели 3–5, около 30 минут), «Жиросжигание» (недели 6–8, около 35 минут, с махами гирей). Программа идёт по счёту тренировок, а не по календарю: пропущенный день не сбивает план.
- **«Нет сил? Хотя бы 10 минут»:** мини-тренировка из 4 упражнений, чтобы день не пропал.
- **Напитки:** лимиты на кофе, энергетики и сладкую газировку снижаются на одну порцию в неделю от вашей привычной нормы до цели (кофе не больше 2 чашек, энергетики и газировка — 0). Приложение считает кофеин и сахар за день.
- **Привычки:** прогулка, белок и овощи, кофеин не позже 15:00, сон. Полоска за 7 дней и серии дней.
- **Вес и талия:** график, ИМТ, сколько осталось до цели.
- **Питание:** калории (если указаны пол и возраст), белок, вода, простые правила и чем заменить энергетики.

Тренировки программы — обычные записи журнала с названием «Перезапуск N/24 · A/B». Они синхронизируются с таблицей, а прогресс программы считается по ним. Не переименовывайте их, иначе тренировка не засчитается.

Привычки, вес и анкета хранятся **только на телефоне**. Чтобы перенести их на другое устройство, нажмите «💾 Копия» и затем «📂 Загрузить копию».

## Как это работает

- Всё сохраняется на телефоне мгновенно, а в таблицу уходит в фоне одной пачкой. Индикатор в шапке показывает состояние: 🟢 сохранено, ⏳ отправляется, 🔴 нет связи (всё уйдёт само, когда связь появится).
- При открытии приложение сразу показывает данные с телефона, а свежие подтягивает из таблицы в фоне.
- Во время тренировки экран не гаснет, чтобы таймер отдыха точно подал сигнал. Это отключается в ⚙️.

## Обновление

- **Интерфейс:** загрузите новый `index.html` в репозиторий. На телефоне новая версия появится со второго открытия. Если изменений много, увеличьте номер версии в `sw.js` (`moose-v3.0` → `moose-v3.1`).
- **Картинки упражнений** лежат в папке `img/` (готовые комплексы — во вкладке «Шаблоны»). Новые картинки добавьте также в список `SHELL` в `sw.js`, чтобы они открывались без интернета.
- **Скрипт:** после правки `Code.gs` — «Управление развертываниями» → ✏️ → «Новая версия». Ссылка `/exec` при этом не меняется.

## Если что-то не так

- «Сервер ответил не так, как ожидалось» — у развёртывания не стоит доступ «Все» или ссылка не та (нужна заканчивающаяся на `/exec`, не `/dev`).
- «Неверный ключ доступа» — ключ скопирован не полностью, или setupToken запускали повторно (тогда действует только последний ключ).
- «На сервере не задан ключ» — не выполнен шаг 1.3.
- Ключ утёк — запустите setupToken ещё раз и введите новый ключ на своих устройствах.
